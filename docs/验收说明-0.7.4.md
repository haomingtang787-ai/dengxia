## 这次改了什么

0.7.3 的课堂页虽然已有三栏数据和行为，但实际界面仍带全局顶栏、顶部大标题、全局搜索和旧版导航，与用户确认过的设计稿不一致。0.7.4 只改课堂页的呈现层和默认入口，不动课程、消息、引用、用量等业务契约。

- **去掉课堂页全局顶栏**：`.app.teacher-app` 下隐藏 `.top-stack`，不再出现“灯下 + 文稿 / AI 私教 / 复习 / 模型·已配置”的全局栏。
- **三栏真实落地**：`.ws-study` 固定 `268px / minmax(0, 1fr) / 332px`；左栏深绿品牌、新建课程、搜索、课程树，中栏 86px 头 + 对话 + 150px composer，右栏“这一讲”四张白卡 + 快捷提问 + 本地优先。
- **默认进入老师页**：根视图默认 `study`，`?view=doc` 仍可回文稿页；旧文稿/复习入口保留在左栏底部。
- **中栏改成对话流**：开课与总览是老师消息，每一讲用细线分隔后成为连续的“老师”消息；原句作为轻量 `p.N + 引文` 行，不再整块堆讲稿头；“停一下”收成可展开的一行。
- **引用卡横向化**：左侧整页图，右侧原句 / 说明 / “打开这一页”，点开仍是整页原图 + 原句弹层，不裁剪页图。
- **信息减法**：课程前缀在左栏课件名和面包屑中剥离；顶栏长标题只保留冒号前的讲名；非错误提示条在老师页隐藏，错误仍以浮层显示。
- **1366 抽屉改成让位而非覆盖**：右栏打开时 `.ws-study.right-open` 变成 `232px / 1fr / 340px` 三列，中栏缩窄，composer 的模型、用量和发送按钮不再被抽屉盖住。
