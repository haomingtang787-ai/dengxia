## 这一版新增

- **默认模型改成 DeepSeek**：模型弹窗打开时，地址已经填好
  `https://api.deepseek.com/v1`，模型名已经填好 `deepseek-chat`。你只需要贴密钥。
  保存过的配置仍然优先，不会被默认值覆盖。
- **拉取模型，不用手打**：弹窗里点「拉取模型」，它会带着当前地址和密钥请求
  `GET /models`，把服务端返回的模型列成下拉框。选一个，模型名自动回填，再点「保存」。
  还没保存的地址和密钥也能直接用来拉取；密钥输入框留空时沿用已保存的密钥。

## 五分钟验收

1. 双击桌面「案头」。
2. 导入一份 TXT / PDF / DOCX（仓库里可用 `tests\fixtures\sample.txt`）。
3. 文稿页点「本地拆讲」——离线也能用，不依赖模型。
4. 顶部点「模型」：
   - 地址、模型名应该已经是 DeepSeek 默认值；
   - 粘贴 DeepSeek 密钥；
   - 点「拉取模型」，应该出现模型下拉框；
   - 选 `deepseek-chat`（或 `deepseek-reasoner`），点「保存并测试」。
5. 回文稿页点「模型拆讲」，看是否按原文生成 2–3 个小讲。
6. 上课页点「听懂了，下一讲」；底部「这一页的题」做一题；再点「生成课后笔记」。
7. 顶部「复习」看到期卡片和错题本。

## 已知边界（不要当成已做）

- 真实 DeepSeek 接口没有测过：没有 key。验证用的是本地假模型服务（OpenAI 兼容），
  测到的是「弹窗 → IPC → fetch /models → 解析 → 下拉回填」整条路径。无密钥探测已确认
  `https://api.deepseek.com/v1/models` 存在（返回 401 鉴权失败，不是 404）。
- 模型拆讲的真实效果同样没有用真实模型验证；失败会明确报 `AI_FAILED`，不会静默降级。
- Word / PPT 页面转换仍然关闭；PPTX / DOCX 只从文件结构提字。
- 没有图片、扫描件、图表识别；大纲只读；笔记不落库、不搜索、不导出。
- 密钥明文保存在本机 `settings.json`，只留主进程，不下发给界面。
