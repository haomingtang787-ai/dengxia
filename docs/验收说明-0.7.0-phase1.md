> 不含：7 个教学技能完整路由、题测/大纲/查找工具、全屏常驻右侧老师栏、安装包、push、GitHub release。

## 一、这一版做了什么

- schema 从 v10 升到 v11，新增 `teacher_persona`、`learner_profile`、`teacher_memory`、`teacher_notes`，并给 `study_sessions` 增加 `teacher_snapshot_json`。
- 默认人格为“老师”，默认学生档案为空；改名只改称呼/人格展示名，不改历史课堂快照。
- 新增 `TeacherStore` 与 `TeacherService`，负责人格、档案、记忆的读写、校验、上下限与重置。
- 记忆支持 `goal / mastery / misconception / preference / strategy / constraint`；同 `kind + subject + concept` 更新旧条；活跃记忆上限 40，按“已确认优先、置信度、最近出现”保留；注入最多 6 条、总字符预算 800。
- 开课时把老师快照写进 `study_sessions.teacher_snapshot_json`；开课和追问都把人格、学生档案、相关记忆注入提示词。
- 下课时先保存学习分析总结，再尝试生成老师手记；手记失败只写 `console.warn`，不阻断总结。
- 老师手记四段：`summary / worked / stuck / next`；课堂删除时手记级联删除，记忆来源置空但不丢记忆。
- 新增老师 IPC/preload API：`teacher.overview / personaSave / profileSave / memoryList / memorySave / memoryDelete / reset / noteList / noteGet`。
- 顶部 tab 从“AI 私教”改为“老师”；老师页新增“老师档案”入口；抽屉里可改名、目标、水平、学科、每周分钟、考试日期、备注，显示“她记得你什么”，可手动记一条、两击删除、两击重置。
- 老师页新增“老师手记”卡片；老师改名后，课堂页头上的称呼也会跟着变。
- 版本号从 0.6.1 升到 0.7.0。
