# 案头 0.2.5 验收说明

## 这一版改了什么

0.2.5 把「点按钮才读」改成「导入后自己读」：

- 文件导入、页面解析完成后，程序自动按页跑完整流程，不需要再点「识别这一页文字」「让模型看懂这一页」「联网查证这一页」。
- 图片页自动顺序执行：本机 OCR → 当前模型读图 → 联网查证。
- 文字页（PDF / PPTX / DOCX / TXT 等）直接使用已解析的页面文字自动联网查证；没有文字的页面会跳过查证。
- 每一页的处理结果都落库；关掉程序再打开，已经读过的页不会重复调用模型，只补没读的部分。
- 填好模型密钥并保存后，当前打开的文稿会自动补跑读图和查证，不需要重新导入。
- 自动流程有进度提示，例如「正在自动读懂第 3 / 12 页（第 3 页）…」；失败时只会在一页上留「重试这一页」，正常情况没有需要点的按钮。

自动读懂的范围：

| 页面类型 | OCR | 模型读图 | 联网查证 |
|---|---|---|---|
| 图片 / 扫描件 | 自动，本机离线 | 自动 | 自动 |
| 文字型 PDF / PPTX / DOCX / TXT | 不跑 | 不跑 | 自动，用已解析的页面文字 |

## 忽略作者，只留知识点

用户明确要求不要作者、机构、版权这类信息，直接聚焦知识点。0.2.5 做了四层处理：

1. 本机 OCR 落库前就过滤「作者 / 主编 / 编者 / 出版社 / 版权 / ISBN / DOI / 责任编辑 / 作者简介 / 通讯作者」等元信息行，不再把它们显示成页面文字。
2. 模型读图的提示词要求：作者、机构、版权页、页眉页脚、页码、日期、致谢、参考文献列表一律忽略，只抄知识点和讲解要点。
3. 联网查证的搜索词优先使用模型读图文字，而不是 OCR 的错字；并过滤元信息行，搜索词里不再出现「作者：张三」。
4. 讲课提示词也要求忽略作者、机构、版权页、页眉页脚、页码、日期、致谢和参考文献列表，只围绕学科知识点拆讲；页面底部原来显示的「来源信息」作者字段已去掉。

## 五分钟验收

1. 双击桌面「案头」，确认「模型」里已是 `deepseek-flash` 且密钥已保存。
2. 直接导入一张带中文的图片，**什么都不要点**。
3. 稍等，页面顶部出现「自动理解」；进度走完后，页面下方应依次出现：
   「识别出的文字」「模型读图」「联网查证 + 参考来源」。
4. 图片里如果写了作者、单位、版权字样，OCR 卡和查证内容里不应再出现这些行。
5. 关掉文稿再打开，结果仍在；再点「重试这一页」只在这一页自动失败时才会出现。
