# 案头 0.4.0 验收说明

> 验收对象：源码工作副本 `teacher-agent-stage1-r2`（版本 0.4.0，schema 6）
> 验收时间：2026-11-16
> 验收方式：离线单测 + 真实窗口界面冒烟（本地假模型）+ 数据库核对
> **未包含**：真实第三方模型调用（等你的 key）、Windows 安装包重打

## 这一版解决的是什么

0.3.0 的链路已经跑通，但「完整读懂课件」有三处是空的，长课件还会被截断，总结也没有学生作答作证据。
0.4.0 只补这些：

1. **PPTX 表格与演讲者备注**进入正文（以前表格文字整块丢失，备注直接跳过）；
2. **DOCX 内嵌图**被单独取出、落资源、按块送视觉模型（以前写成「内嵌对象，未读取」）；
3. **扫描版 / 图多的 PDF 页**自动补 `image_region` 块并触发整页读图（以前只报「没解析出文字」）；
4. **长课件不再截断**：按页切成最多 12 段逐段读懂，再据分段理解拆课，覆盖到最后一页；
5. **「停一下」的问题可以作答**，作答落库，并作为学习分析总结的判断证据。

### 一个被测试挡住的问题

DOCX 内嵌图第一次跑测试时被 ZIP 的压缩比上限拒绝：12KB 的全零假 PNG 压缩后只有几十字节，
被当成压缩炸弹。测试改用随机字节后通过——这也说明这条上限确实在工作，不是摆设。

### 这一轮顺手修的布局问题

- 讲稿主栏在 1280 宽的三栏布局里只剩十几字一行，逐句讲解读不下去。
  断点从 1240 提到 1440：这个宽度以下把「整份材料总览 / 学习分析总结」移到正文下方，正文栏拿到完整宽度。
- 作答保存后输入框回落到已保存答案，不再变成空框。

## 未验证 / 不能当成通过

1. **真实第三方模型**：本轮全部用本地假模型。真实 DeepSeek 的拆课质量、逐句讲解长度、
   分块理解在 10 万字以上材料上的稳定性，都还没有真实调用证据。
2. **真实 PPTX 表格/备注样本**：只有构造夹具，没有拿你手上的课件跑过。
3. **真实 DOCX 图解题**：只有 64×48 的测试图，没有跑过教材里的大图、公式截图、EMF 图元。
4. **超长课件**：分块逻辑有单测，但没有一份真实 30 万字以上的课件跑完整条链路。
5. **Windows 安装包**：本轮没有重打 NSIS。`dist/desk-setup-0.3.0.exe` 不含这些改动。

## 你可以怎么验收（需要你的 key）

1. `npm ci && npm test`，确认 161 项通过；
2. `npm run dev`，在「模型」里填你的 API 地址、模型与密钥，点「测试」；
3. 上传一份**带表格和备注的 PPTX**：看大纲里是否出现表格内容；点开一讲，看 `explain` 是否贴着表格讲；
4. 上传一份**有插图的 DOCX**：看是否出现「本页图片/图表」的理解内容，而不是「未读取」；
5. 在任一「停一下」下写一句答案 → 应出现「已记录，会进入学习分析总结」；
6. 追问两轮 → 生成总结，检查 `mastered / weak / pitfalls / next` 是否引用了你的作答；
7. 若手上有 100 页以上课件：关注界面顶部是否显示「已分 N 段逐段读懂」，以及最后一讲是否覆盖末页。

把 3–7 的真实结果（截图或描述）发回来，我再把「真实模型验收」这一段补齐；
如果哪一步不对，按对应的失败路径改，不靠调提示词掩盖结构问题。
