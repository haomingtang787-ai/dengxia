# 灯下 0.7.5 验收说明

> 版本：`0.7.5`（`package.json` / `package-lock.json` 已改）
> 主题：老师页继续做“界面减法”，让课程操作、导入和模型切换都留在同一张课堂页。
> 状态：源码、全量测试、真实 Electron 窗口、打包、覆盖安装与 GitHub release 均已完成。

## 这次改了什么

0.7.4 已经把老师页对齐成左课程 / 中对话 / 右上下文，但入口仍有两处割裂：

- 左栏底部还留着「文稿库」，点开后会离开课堂页；
- 底部 composer 的模型只是只读文字。

0.7.5 按“保留功能，但界面更简洁”处理：

- **去掉可见的「文稿库」入口**：老师页左栏底部只留「复习」「设置」两个入口；底部从 3 列变 2 列。文稿库对应的原稿管理页没有删除，仍可通过 `?view=doc` 打开，只是不再作为课堂页的主入口。
- **导入课件搬到「新建课程」旁边**：左栏顶部改为两列按钮，「＋ 新建课程」深绿主按钮 + 「⇧ 导入课件」白底次按钮；1366 窄屏仍是并排两按钮，不换行、不溢出。课程空态、头部操作和「更多」菜单里的文案统一为“导入课件 / 导入另一份课件”。
- **导入后自动接住拆课**：`onImport` 返回最后导入的 `documentVersionId`；只在“刚导入且还没有 session”的文稿上清空旧课堂，让页面回到自动拆课进度。普通启动、普通切换课程不会误触发。
- **底部模型可切换**：composer 右侧的 `deepseek-flash` 从只读文字变成 `select`；启动时读取 `ai.status()`，预取 `ai.models()`，失败时回退 `deepseek-chat` / `deepseek-reasoner`。切换时调用 `ai.saveConfig`（空 key 沿用已保存 key），下一句起生效，并给轻提示。选择过程中禁用，避免重复提交。
- **其他保留**：导入、课程树、对话、讲次分隔、引用页图、用量、复习、设置、老师档案均未删。

## 取舍与未做

- 文稿库入口隐藏后，文稿级重命名/删除/置顶仍只在隐藏的 `?view=doc` 页面里；本轮按“当前界面就够”没有把它们塞回左栏。若需要，可在课程树的文档行右键菜单里补一个轻量入口。
- 导入按钮走系统文件选择器；本轮验证了组件接线和真实布局，没有在原生选择器里自动点选文件。
- 模型候选来自 DeepSeek `/models` 实际返回；本机测试库只有 `deepseek-flash` / `deepseek-v4-pro`，没有做更广的模型列表适配。
