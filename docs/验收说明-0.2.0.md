## 五分钟验收

1. 安装（可以换目录），启动「案头」。
2. 导入一份 TXT / PDF / DOCX（仓库里可以用 `tests\fixtures\sample.txt`）。
3. 文稿页点「本地拆讲」——不需要联网，按原文拆成小讲，自动进「上课」。
4. 顶部点「模型」，填地址、模型名、密钥，点「保存并测试」；成功后回文稿页点「模型拆讲」。
5. 上课页：点「听懂了，下一讲」、切「慢一点」、试「暂停在这」；下方「这一页的题」选一个答案。
6. 顶部「复习」：到期卡片「看答案 → 记得 / 忘了」；答错的题出现在错题本。
7. 上课页底部「生成课后笔记」，内容是听懂进度、还没懂的小讲、错题和到点卡片。

## 模型配置示例

- OpenAI：地址 `https://api.openai.com/v1`，模型 `gpt-4o-mini`
- DeepSeek：地址 `https://api.deepseek.com/v1`，模型 `deepseek-chat`
- 只要兼容 `POST /chat/completions` 即可。密钥只保存在本机
  `%APPDATA%\desk-teacher-agent\library\settings.json`，不会下发给界面。
