# 0.7.1 验收说明：老师会选教学技能、会调用本地工具

日期：2026-11-17  
状态：代码实现与本地验证完成；0.7.1 未单独发版，已与 0.7.2 一起合入 `v0.7.2` 提交与 GitHub release。

## 一、这次改了什么

### 1. 七个教学技能路由

老师不再只有“讲解/对话”一种回复方式。`StudyService.send` 接受可选的：

- `mode: 'direct' | 'guided'`，默认 `direct`
- `skill: 'auto' | 'diagnose' | 'explain' | 'socratic' | 'quiz' | 'error' | 'review' | 'teachback'`，默认 `auto`

`auto` 只选一个主技能，不把七套提示词同时叠进上下文。每个技能在 `src/study/tools.ts` 里有独立触发词；`src/study/prompt.ts` 只追加一段最具体的技能约束。模型失败或没遵守技能约束时，仍然退回普通讲解。

七个技能各自管什么：

| 技能 | 触发例子 | 约束 |
|---|---|---|
| `diagnose` | 带我学、先问我、不知道从哪开始 | 一次只问一个前置问题，最多 2–3 个；学生说“直接讲”就停问 |
| `explain` | 这一句是什么意思 | 例子 → 规则 → 反例 → 一句话总结，必须贴原文 |
| `socratic` | 多问我、别直接告诉我 | 一次只问一个 why / how / 如果…会怎样，不替学生答 |
| `quiz` | 考考我、出题、测一测 | 1–3 道主动回忆题，先答后判，题面不泄露答案 |
| `error` | 我哪里错、为什么错 | 概念错 / 步骤错 / 审题错三类，必须引用原文或学生原话 |
| `review` | 安排复习、怎么复习 | 结合到期卡、错题、手记安排下一次；一次最多 10 张卡 |
| `teachback` | 我讲给你听、复述 | 让学生讲，不替学生讲；按原文指出具体缺口，不虚假夸奖 |

### 2. 五个可落库的本地工具 + 判题

新增 `study.tool` 聚合通道，不接受任意工具名，只认六种动作：

| 动作 | 做什么 | 落点 |
|---|---|---|
| `search` | 只在当前课程的 `study_units` 里查，返回讲次、原句、页码；没命中明确说“没找到” | `study_artifacts` 的 `search`，scope `course` |
| `summary` | AI 基于当前讲/整门课材料生成纯文本总结，附原文 citations | `summary`，scope `unit:N` 或 `course` |
| `outline` | 只从 `study_units` 的标题、keyPoints、source 抽结构，不编造章节 | `outline`，scope `unit:N` 或 `course` |
| `quiz` | AI 出 1–3 道开放题；返回体只有题面/提示/出处，不含答案 | `quiz`，scope `unit:N` 或 `course` |
| `quiz-grade` | 接收学生逐题作答，AI 判题，反馈和缺口写回同一份 quiz artifact | 更新同一条 `quiz` |
| `teachback` | 学生复述 20–2000 字，AI 按原文给 covered / gaps / feedback | `teachback`，scope `unit:N` 或 `course` |

配额与边界：`search` 查找词 1–80 字；`quiz-grade` 一次最多 3 题、每题答案 ≤1200 字；每门课最多保留 20 条 artifact；同一 `session_id + kind + scope` 只保留一条，第二次生成覆盖旧结果。

### 3. 自然语言直接入口

除了 UI 菜单，学生直接在对话框里说这些话，也会先走一次性工具，不再让模型陪聊一遍：

- “找原文：DRAM 刷新” → 本地查找
- “读原文：DRAM 刷新” → 同一套本地查找
- “总结这一讲” → 生成总结并落库
- “列一下复习大纲” → 抽大纲并落库
- “考考我这一讲” / “题测一下” → 出题并落库
- “我讲给你听：DRAM 是电容，靠刷新保持数据……” → 复述反馈

普通问题（如“这一句是什么意思”）仍然走讲解。自然语言工具入口和 UI 入口共用同一个 `StudyService.tool`，避免两套逻辑。

### 4. 界面入口

没有新增顶部 tab，也没有第二排工具条。老师页“更多”菜单新增一组“老师能做什么”：

- 总结这一讲
- 考考我这讲
- 列复习大纲
- 找原文
- 我讲给你听

点击后打开“课程资料”抽屉，结果以卡片形式出现；题测卡有逐题 textarea，全部答完才出现“交给老师判”；判完显示反馈和 gaps。搜索卡有输入框，复述卡有 textarea。1366×768 下菜单有 `max-height` 和内部滚动，不会把下面的“删除这门课”裁出屏幕。

### 5. 存储与接口

- schema 从 11 升到 12，新增 `study_artifacts`，删除课程级联删除。
- `StudyStore` 新增 `listArtifacts` / `findArtifact` / `upsertArtifact`。
- `StudyService.detail` 返回 `artifacts`；`src/shared/study.ts` 新增 `StudySkill`、`StudyMode`、`StudyToolKind`、`StudyArtifact`、`StudyQuizQuestion`、`StudyQuizAnswer`、`StudyCitation`、`StudySearchMatch`、`StudyOutlineItem`。
- IPC 新增唯一通道 `study.tool`；preload 暴露 `window.desk.study.tool(...)`；`study.send` 的 preload 类型也加了可选 `mode` / `skill`。

## 五、已验证 / 未验证 / 已知边界

### 已验证

- 老师页真实窗口能走通“更多 → 列复习大纲 → 课程资料工具面板”，能看到生成的复习大纲。
- 真实窗口能走通“更多 → 找原文 → 输入正交 → 8 处命中”，artifact 写入并显示。
- 1366 窄屏工具面板不横向溢出；菜单有内部滚动。
- 全量测试、typecheck、build 均通过。

### 只测到服务层，真实窗口未逐项点击

- `summary`：服务层 fake fetch 已测生成、覆盖、citations；真实窗口没点“总结这一讲”，因为会消耗真实模型额度。
- `quiz` / `quiz-grade`：服务层已测出题不含答案、提交后判分；真实窗口没点“考考我这讲”，也没提交过作答。
- `teachback`：服务层已测复述缺口；真实窗口没点“我讲给你听”。

这些不是“已经验收通过”，只是实现和单元测试通过。后续要逐项点真实窗口时，应使用隔离 userData，不要碰真实用户库。

### 已知边界

1. `memory` / `notes` / `read` / `cards` 没有注册成新的工具动作。它们分别走现有老师档案、`finish()` 手记、提示词上下文和复习页。首版不为了凑 8 个工具而复制已有能力。
2. `mode='guided'` 只有提示词行为，UI 没有“直接答 / 带我学”切换；聊天输入默认 `auto`。
3. 题测 artifact 独立落库，尚未写入 `lecture_quizzes` 或 `misses`；“错题进错题本”未实现。
4. 真实窗口没有点击“总结/题测/复述”的 AI 生成路径；服务层测试不能替代真实模型和真实窗口验收。
5. 0.7.1 尚未 commit / push / tag / release；安装包和 GitHub release 仍是 0.7.0。
6. `computer_use_tool` 当前报 `gui_global_disabled`，界面验收使用 `DESK_SMOKE_SHOT` / `DESK_SMOKE_ACTION` 在真实 Electron 窗口完成。
