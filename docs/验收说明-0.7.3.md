# 灯下 0.7.3 验收说明

> 版本：`0.7.3`（`package.json` / `package-lock.json` 已改）

## 1. 一句话结论

课堂页已经从“讲稿 + 抽屉对话”改成真正的三栏老师工作台：

- **左栏**：课程 → 课件 → 讲，课程可改名/排序/删除，左栏可收成 56px。
- **中栏**：一份课件 = 一个连续对话；讲与讲之间只有一条细线 + 小字，不拆会话。
- **右栏**：当前讲知识点、老师手记、生成物、这份课件用量；1366 宽收成 330px 抽屉。
- **对照讲义**：老师回答按 PPT/PDF 原页给整页图，不裁剪；有逐字匹配的 block 时叠 bbox 黄框，找不到就只显示整页图 + 校对后的原句，不伪造高亮。

外层“文稿”栏在老师页已经隐藏，工作台自身就是三栏；需要导入或管理文稿时，仍可从顶部“文稿”或左栏底部“文稿库”进入。

## 6. 已知边界

1. **扫描 PDF 的 OCR 噪声**：测试库里的线性代数 PDF 是手写扫描件，OCR 文本与真实页面文字对不上。当前策略是“找不到逐字匹配就不画框”，用老师讲稿里校对过的原句，并显示整页图；这比把黄框放错位置更安全。PPTX/文本型 PDF 有干净 block 时会画 bbox 黄框（单测已覆盖）。
2. **无页图格式**：DOCX/TXT/Markdown 或 PPTX 渲染失败时走原句卡；代码路径已实现，但本轮没有专门的无页图截图。
3. **测试库不是干净演示库**：`%TEMP%\desk-073-workspace` 里有真实发送的消息和早期播种的 citation，仅用于 UI 验收；真实用户库未被使用。
4. **未发布**：版本号已改到 0.7.3，但没有 commit/push/tag/release。0.7.2 的 release `447895526` 仍是 latest。
