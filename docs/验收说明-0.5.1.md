# 灯下 0.5.1 验收说明：油灯图标、讲解放大、可收放侧栏、网页端检查更新

> 验收对象：`DengXia-setup-0.5.1.exe`
> 时间：2026-11-16

## 这一版改动

1. **图标借鉴油灯**：参考你提供 `灯下.exe` 的「油灯」图标，重画为深青绿圆角底 + 米白油灯剪影（火苗 + 灯托 + 灯身 + 底座）+ 暖黄火苗。`scripts/build-icon.mjs` 可随时改配色重跑。
   - 顺带新增 `scripts/extract-icon.mjs` / `dib-to-png.mjs`：能从 exe 里解析 PE 资源提取图标并转 PNG（供以后借鉴别的图标用）。

2. **讲解是主体、最大最醒目**：
   - 讲解正文 17px、加粗、行距 1.9，颜色加深；
   - 「原文」降为 13.5px 的次要层，带橙色「原文」小标签。

3. **侧边栏可收放**：
   - 左侧「课程大纲」和右侧「总览与总结」各有一个收起/展开按钮；
   - 收起后折成 44px 细边，正文自动变宽。宽屏实测：三栏 230/608/290 → 全收起后正文 1040px；窄窗大纲收起后正文 620→776px。

4. **检查更新走 GitHub 网页端**：改为 `fetch https://api.github.com/repos/haomingtang787-ai/dengxia/releases/latest`，公开仓库无需鉴权、不依赖 gh CLI。仓库可用 `DENGXIA_UPDATE_REPO=owner/repo` 覆盖。

## 验收结果

- 两套 `tsc --noEmit`、`vitest run`（171 项）、`npm run build`、`npm run dist:win` 全部通过。
- 窗口冒烟（本地假模型）：
  - 侧栏收放探针：`before 200px` → 收起大纲 `44px`（正文 620→776px）→ 再收起总览 → 恢复 `200px`，`expandCount=2`；
  - 宽屏三栏：230/608/290 → 全收起 44/1040/44；
  - 讲解放大、原文标签、两侧收起按钮均正常。

- 版本 0.5.1 已打包 `DengXia-setup-0.5.1.exe`，更新发布文件夹，并推送 GitHub release v0.5.1（覆盖安装时旧数据在 `%APPDATA%/灯下` 原样保留）。
