## 自动化断言（0.6.1 新增）

`tests/features-061.test.ts`，6 项：

1. 正常备份的 manifest 含 64 位 `database.sha256`、`sizeBytes`、`integrity='ok'`、`files`、`bytes`；恢复预览 `verification='sha256'`，`databaseSha256` 与 manifest 一致。
2. 备份库改一个字节后，`inspectRestore` 失败，错误信息含「校验」，不进入 `applyRestore`。
3. 把备份库换成非 SQLite 内容、同时伪造正确哈希，仍被 `PRAGMA integrity_check` 拒绝，错误信息含「SQLite」。
4. 删掉旧 manifest 的 `database`/`files`/`bytes` 后，预览仍成功，但 `verification='legacy'`、`databaseSha256=null`。
5. 高亮所在 block 文本改为「矩阵的迹等」后，列表返回 `valid=false`、`reason='quote_changed'`；`cleanupHighlights` 删除 `deleted=1`，清理后列表为空。
6. 插入一条 0/0/0 用量后，`BudgetService.status()` 返回 `estimatedCalls=1`、`estimated=true`、`used=0`；再插入 20+10 用量后 `used=30`，但仍提示估算（因为仍有未计量调用）。

`tests/search.test.ts`，新增 25 条命中分页断言：第一页 20 条，`total=25`；`offset=20` 第二页 5 条。
