> 日期：2026-11-17

> 不含：7 个教学技能完整路由、题测/大纲/查找工具、安装包、push、GitHub release。

## 一、这一版做了什么

- 老师手记的模型输出增加可选 `memories[]`；每条 `{kind, subject, concept, statement}`，只接受 6 种合法记忆类型，最多保留 2 条。
- 下课时先把学习分析总结和老师手记落库，再把观察写入 `teacher_memory`：`userConfirmed=false`、`status=active`、来源写入当前 session 和 document version。
- 观察写入使用同 `kind + subject + concept` 的 upsert：不重复新增；已由学生确认的旧条不会被观察覆盖或降级；记忆写入失败只 `console.warn`，不阻断总结或手记。
- 老师档案抽屉新增观察的“确认 / 改写 / 删除”：确认后 `userConfirmed=true`；改写保留原来源和确认状态；两击删除。
- 新增 `teacher.noteSave` / `teacher.noteDelete` IPC/preload：手记总览、讲通、卡住、下次先做四段可编辑；删除后 `teacherNote=null`，学习总结不受影响。
- 老师页 header 新增“课程资料”抽屉，收进整份材料总览、学习分析总结、老师手记和 API 用量；右侧常驻“总览与总结”栏移除，主区只剩大纲 + 讲解。
- 课程资料抽屉在宽屏两列、640px 以下单列；1366×768 下不横向溢出。
- 备份恢复测试增加老师资产断言：恢复后 `teacher_persona`、`learner_profile`、`teacher_memory`、`teacher_notes` 仍在。
- 新增冒烟动作：`course-materials`、`teacher-note-edit`；`teacher-note` 改为先打开课程资料抽屉。
