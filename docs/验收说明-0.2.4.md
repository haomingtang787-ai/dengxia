# 案头 0.2.4 验收说明

## 这一版加了什么

0.2.4 把「联网查证」做成独立按钮，不把搜索塞进读图请求：

- 页面工具栏新增「联网查证这一页」。
- 点击后先取这一页的 OCR / 模型读图文字；如果图片页还没有读数，会先自动跑本机 OCR，
  不会把「图像已作为预览保留……」这条界面提示当成页面内容。
- 再用页面文字调用 DeepSeek 的 `POST /v1/tools/search`，取回 5 条网页结果。
- 最后把「页面内容 + 搜索结果」交给当前模型，只输出三节：
  「核对结论」「需要补充或修正」「讲课建议」，引用写成 `[1][2]`。
- 结果连同来源一起存进新表 `page_research`，同一页重复查证会更新，不会堆重复记录。
- 结果卡标题是「联网查证」，下面列出「参考来源」：标题、站点、URL、摘要。

搜索目前只支持 DeepSeek 官方地址 `api.deepseek.com`。换自定义 OpenAI 兼容网关时，
「联网查证」会直接报「只支持 DeepSeek 官方地址」，读图和讲课不受影响。

## 遇到的一次空返回，以及最后的处理

第一次真实查证成功落库（answer 1856 字、5 条来源），后面重跑同一条流程时，
界面提示「模型没有返回内容」，`page_research` 为空。

DeepSeek 官方文档写明：`deepseek-flash` 的思考模式默认开启，默认 effort 为 `high`，
思维链也占输出额度。查证请求原来和其他请求一样走默认思考模式，只给了 3000 输出预算。
0.2.4 现在把「联网查证」这一步显式改为 `thinking: {"type": "disabled"}`，让模型直接给
核对结论，不再先写一大段思维链。改完后重新打包、安装，再用真实密钥连续跑同一条查证，
成功落库。此前那次空返回是否完全由思考 token 吃满额度造成，没有逐 token 复现，
但关闭思考后不再复现，这条修复是当前版本的稳定路径。

讲课和读图仍然保留默认思考模式；只有查证这一步关闭思考，以便更快给出核对结论。

## 五分钟验收

1. 双击桌面「案头」，点「模型」，确认模型是 `deepseek-flash`，密钥已保存。
2. 导入一张带中文的图片（扫描件、课件截图都可以）。
3. 点「识别这一页文字」，应出现「识别出的文字 · windows-ocr」卡片。
4. 点「联网查证这一页」，应出现「联网查证 · deepseek-flash+search」卡片：
   先看到「核对结论」，下面有「需要补充或修正」「讲课建议」，再下面是「参考来源」。
5. 关掉文稿再打开，查证结果仍在；再点一次「联网查证这一页」会更新同一页的记录，
   不会多出一条重复记录。
