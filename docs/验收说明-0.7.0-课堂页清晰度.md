# 灯下 0.7.0 课堂页清晰度补充验收

> 日期：2026-11-17
> 范围：只改现有课堂页的布局层级、学习路径和文案；不改服务接口、数据库、0.7.1 技能路由。
> 隔离副本：`%TEMP%\desk-070-userdata`；真实用户库未碰。

## 一、这次改了什么

- 顶部从 5 个平铺动作收成 3 个：`课程资料`、`更多`、`问老师`。原来的蓝色主按钮“用当前文稿再开一门”不再是首屏主操作，收进“更多”。
- “更多”菜单分两组：`这门课` 放老师档案、回到文稿库、用当前文稿再开一门；`收尾与整理` 放学习总结与老师手记、清除对话、清除总结、删除课程。删除仍是两击确认。
- 课程页增加一条四步学习路径：`选一讲 → 读讲稿 → 答“停一下” → 问老师`。
  - 点“选一讲”会展开大纲并聚焦当前讲。
  - 点“读讲稿”会滚回本讲顶部。
  - 点“答“停一下””会滚到第一个答题框并聚焦。
  - 点“问老师”会打开对话并聚焦输入框。
  - 右侧另给“学完这讲，去生成总结”，直接打开课程资料抽屉。
- 大纲标题下补“点一讲切换；绿色是正在学”，当前讲有 `aria-current`。
- 讲稿头补“读法：先看原文 → 再看讲解 → 遇到“停一下”写一句；不懂就点“问老师””。
- 对话从常驻底栏改为真正的随叫随到抽屉：收起时只在右下角留“问老师 · n 条记录”；展开后是浮动对话面板，不再把讲稿挤没。宽屏和 1366 都用同一套抽屉规则。
