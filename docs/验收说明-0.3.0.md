# 案头 0.3.0 验收说明

> 验收对象：`dist/desk-setup-0.3.0.exe`
> 验收时间：2026-11-16
> 验收方式：开发版真实 API 全链路 + 安装版真实 API 全链路 + 安装包/快捷方式/数据库核对

## 这一版解决的是什么

0.2.x 的做法是“逐页识别 + 一次性拆讲”。用户明确否定这个方向，认为它只是识别和摘要，不是老师上课。

0.3.0 推倒重来，做成一条完整闭环：

1. 上传课件；
2. Agent 自动把整份材料接收并读懂，不要求用户再点“识别”；
3. 基于用户自己的 API 配置进行多轮对话；
4. 按用户自己的学习习惯拆成一份一份的小课；
5. 每一讲按“原文句子 → 老师逐句讲解 → 停一下的问题”讲；
6. 学完生成学习分析总结。

## 用户实际看到的流程

1. 在「文稿」页点「导入」，选择 PDF、TXT、Markdown、图片，或 PPTX / DOCX；
2. 图片页自动进入 AI 读图，文字页直接取结构文字；不再需要点“识别”；
3. 打开「AI 私教」，如果当前文稿还没有课堂，界面自动创建课程，不再需要点“拆课”；
4. 页面出现：
   - 整份材料总览（说明这份材料到底在讲什么）；
   - 按个人习惯拆好的课程大纲；
   - 当前小讲的逐句讲稿；
   - “停一下”问题；
   - 课堂消息与追问输入框；
5. 用户输入追问，模型带着课程总览、大纲、当前讲稿和最近对话回答；
6. 点「生成学习分析总结」，得到已掌握 / 还不稳 / 容易错 / 下一步。

## 后端怎么实现

### 数据模型（schema 5）

- `study_sessions`：一门课。保存整份材料总览、大纲、创建时的习惯快照、读取警告、是否截断、材料字数、状态、总结。
- `study_units`：一讲。保存标题、目标、分钟数、原文句子 / 老师讲解 / 停一下问题的 `segments_json`。
- `study_messages`：课堂消息。保存 user / assistant 角色和所属小讲。

创建会话、单元、开场消息在一个事务内完成；课程创建失败不会留下半成品。

### 服务编排

- `create`：检查 API 配置 → 收集整份材料 → 调模型做课程设计 → 解析并落库 → 写开场消息。
- `send`：带整门课总览、大纲、当前小讲逐句稿、最近 12 条消息调用 API；成功后才同时写 user 和 assistant 两条消息。
- `finish`：带整门课和对话生成结构化总结；已有总结直接返回，不重复调用。
- `list` / `get`：返回前端视图。
- 同一 `requestId` 重复创建直接返回已有会话。
- 模型第一次输出不合格（例如某讲只有 1 个讲解层次）时，带错误原因再请求一次，不把半成品落库。

### 整份材料收集

- 文字页取 `blocks`；
- 图片页优先已有 AI 视觉结果，没有则调 `images.vision`，失败才退回本机 OCR；
- 空页和读图失败写入 `warnings`；
- 最多送 100,000 字，超出保存 `truncated` 并在界面提示。

### 个人习惯

沿用原有六项：称呼、讲透/适中/抓考点、先比方/先定义/先提问、一次 15/25/40 分钟、学习时段、避免公式堆/长段落/没例子。

创建课程时冻结当前习惯到 `habits_json`；之后改习惯不会改变已经开始的课。旧 `teaching` / `lectures` 后端保留，但「上课」页不再是主入口。

## 前端怎么实现

- 新增 `src/renderer/study/StudyView.tsx`，替换旧 `ClassView` 作为「AI 私教」主界面。
- Tab 改为「文稿 / AI 私教 / 复习」，`view` 类型为 `doc | study | review`；旧的 `class` 参数兼容映射到 `study`。
- 文稿页移除“本地拆讲 / 模型拆讲”，改成「导入新课件」和「用它开始 AI 私教」。
- 进入「AI 私教」时：
  - 当前没有选中文稿，自动打开文稿列表第一份；
  - 当前文稿还没有课堂，自动创建课程；
  - 手动按钮保留为“用当前文稿再开一门”。
- 讲稿标题使用普通文档流，修复了旧 `.stage header` 的 flex 规则污染，避免“第 1 讲”竖排和标题被挤压。
- 习惯编辑只影响后续新课；已开始课程的「本次习惯」展示创建时快照。

## IPC

`src/shared/ipc.ts` 新增：

- `study.create`
- `study.list`
- `study.get`
- `study.send`
- `study.finish`

`src/preload/index.ts` 暴露 `window.desk.study`；`src/main/ipc.ts` 绑定五个通道；`src/main/index.ts` 实例化 `StudyService`，从 `TeachingService.habits()` 注入当前习惯。

## 已知边界

1. PPTX / DOCX 当前只从文件结构提取文字；页面转换需要经过 LibreOffice 和 Windows 沙箱，0.3.0 没有启用未验证的转换路径。PDF、TXT、Markdown、图片可直接导入。
2. 整份材料超过 100,000 字会被截断，界面保存并提示 `truncated`；还没有做分块汇总。
3. 学习分析总结目前只展示，不自动接入旧复习卡 / 间隔重复系统。
4. 未验证：多页整份文稿的 N 页真机计时；真实第三方视觉模型；GIF / WebP 与超大扫描件；代码签名与 SmartScreen。

## 验收步骤

1. 运行 `dist/desk-setup-0.3.0.exe`，完成安装；
2. 确认桌面出现「案头」快捷方式；
3. 打开「案头」，在「模型 · 已配置」中确认自己的 API 地址、模型、密钥；
4. 在「文稿」导入一份课件；
5. 切到「AI 私教」，不要点“拆课”，确认课程自动出现；
6. 检查课程大纲、逐句讲稿和“停一下”；
7. 输入一句追问，确认老师回复；
8. 点「生成学习分析总结」，确认四组内容出现。
