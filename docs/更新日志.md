## 0.5.4（2026-11-16）
- 修复顶部提示条被撑成整屏高的空框：「已自动读懂 N 页」这类提示只占一行高度，三栏工作区重新填满窗口，内容紧跟顶栏。
  - 原因：`.app` 只声明了 `auto 1fr` 两行，提示条一出现就落进 `1fr` 行被拉满，下面的三栏反而被挤到隐式行。
  - 现在顶栏、提示条各占一行内容高度，第三行 `minmax(0, 1fr)` 专门留给工作区。

## 0.5.5（2026-11-16）
- 新增「删除文稿」：文稿库每行右侧一个「×」，展开后写明影响范围（页面、讲解课、卡片、错题、用量一起删，不可恢复），再点一次「确认删除」才执行。
- 删除前先停掉这份文稿正在跑的解析/读图任务；随后在一个事务里清掉版本、页面、文本块、读图与查证、产物、任务、课程/卡片/错题、学习会话和用量行，最后删原文与页面图目录。
- 删掉当前打开的文稿时，右侧详情、页面与读数一起清空，文稿库总数同步刷新。

## 0.5.6（2026-11-16）
- 文稿整理：文稿栏可按名称搜索、按格式筛选，列表显示「共 N 份 / 找到 N 份」。
- 每行可「置顶」（☆/★，写进 settings.json，重启仍生效）和「重命名」（1–120 字，详情标题同步）。
- 同一个文件再次导入不再堆副本：按 sha256 命中已有版本，直接打开并提示「之前导入过」。
- 复习闭环：设置里可定每天卡片数（1–200）与错题数（0–100），复习页显示今日已评卡进度条；没达标时在 9:00–22:00 弹一次本机通知（每天最多一次）。
- 导出：卡片按 `正面<TAB>背面` 导出 Anki 可导入的 TXT；错题本导出 Markdown（题干、来源、时间、解析）。
- 本机数据：设置里显示库/原文/页面图占用与文稿、页面、课程、卡片、错题、AI 调用统计；可把整库备份到自选文件夹（`VACUUM INTO` 一致性快照 + 原文/页面图 + manifest.json，不含 API 密钥与临时目录）。
- 应用内更新：检查更新会识别 `DengXia-setup-*.exe` 资产，可下载到 `userData/updates`（显示进度），下载完可一键打开安装包覆盖安装。
- 仍不做：正文全文检索跳页、划词高亮/摘录成卡、公式渲染、手机伴读、同步、AI 预算护栏。

## 0.6.0（2026-11-16）
- 全文搜索：顶栏搜索框（Ctrl+K）直接搜正文与页面文字，中文按「单字 + 相邻双字」入库，能搜「特征值」这类连续词；点结果直接打开对应文稿、跳到那一页并高亮命中的那一段。删除文稿时同步清掉索引。
- 顶栏重排：品牌、搜索、提示条收进同一个 `top-stack`，不再各占一整行；「已自动读懂 N 页」只占一行，三栏工作区紧跟顶栏，修掉顶部大块空白。设置弹窗层级也修正，不再被搜索框压住。
- 备份恢复：设置里「从备份恢复…」先校验文件夹、展示备份版本与文稿/页面/卡片/错题/高亮数量，第二次确认后才覆盖；覆盖前把旧库改名 `library.before-restore-*` 留作回滚，恢复后自动重启；本机 `settings.json` 与模型 API Key 保留。
- 自动备份：可开「每天自动备份一次」，自选文件夹，按保留份数（1–30）自动清理；目录为「灯下自动备份/灯下备份-时间戳」，删除前校验目录名与 `manifest.json.product`。
- 卡片管理：复习页可「新增卡片」、对当前卡「编辑 / 暂停」、展开「全部卡片」管理并恢复暂停卡；手动卡和讲课卡共用到点队列，导出也合并。
- 错题重练：错题按五箱调度，答对升箱、答错回零并 1 分钟后重来；复习页直接「再练一次」。
- 划词高亮 / 摘录成卡：页面正文可划词，高亮落库（按 block 原文偏移，服务端截取 quote，1–500 字校验）；点高亮可删除；「摘录成卡」把选中原文带进手动卡。
- 公式渲染：接入 KaTeX，支持 `$...$`、`$$...$$`、`\(...\)`、`\[...\]`；讲解、原文、总结、卡片正反面、AI 私教对话都能显示公式，未闭合或空公式原样保留。
- AI 预算护栏：设置「AI 用量护栏」，按自然月累计输入 + 输出 token，显示本月用量与进度；填 0 关闭，超限默认硬拦截下一次模型调用（`LIMIT_EXCEEDED`），关闭硬拦只提醒。
- 数据与测试：schema 升到 v10（v9 卡片/高亮/错题调度，v10 FTS5 全文索引）；新增 0.6.0 功能测试 7 项，全套 37 个测试文件 / 193 项通过，typecheck、build 均 exit 0。
