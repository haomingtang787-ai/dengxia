# 灯下 · 更新日志

> 应用从「案头」更名而来；`appId` 不变，覆盖安装可无缝升级。

## 0.5.1（2026-11-16）
- 图标改为「油灯」剪影（借鉴你提供 exe 的油灯造型）：米白油灯 + 暖黄火苗，深青绿圆角底。
- 课堂讲解正文放大醒目（17px、加粗、更宽行距），原文降为带「原文」小标签的次要层。
- 课程大纲、总览与总结都改成可收放侧栏：收成 44px 细边，把宽度让给讲解正文。
- 「检查更新」改为从 GitHub 网页端 REST API 拉取最新 release（仓库已公开，无需 gh、无需鉴权）。

## 0.5.0（2026-11-16）
- 应用更名「灯下」，新增台灯 + 书本应用图标与界面 logo。
- 设置弹窗新增「检查更新」入口（占位实现，可走本机 gh 查 GitHub Release）。
- 明确「更新只替换应用文件、绝不清空用户数据」的数据保留约定。
- 首次以全新状态启动（不迁移旧「案头」数据目录）。
- 发布：GitHub Release 随附安装包。

## 0.4.2
- 省钱：分段理解结果按「文稿 + 材料哈希」持久化复用，重开课不再重复读材料付费。
- 省钱：拆课/分段重试提示移到末尾，让 DeepSeek 前缀缓存整段命中。
- 右侧栏新增「API 用量」卡片（调用次数、输入/输出 token、缓存命中率）。
- 界面：固定视口、三栏独立滚动；窄窗下对话改为右下角抽屉、总览/总结压成底部信息带。
